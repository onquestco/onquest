# OnQuest

A home on the web for all your trips. See `CLAUDE.md` for how the code is organised and `docs/` for the product and design specs.

## Run it

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000/demo for the sample Goa trip.

## Check it

```bash
npm run typecheck && npm run lint && npm test
```
